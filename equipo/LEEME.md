# Fichas del equipo

Cada integrante crea en esta carpeta un archivo con su usuario de GitHub.
Por ejemplo, si tu usuario es `maria-dev`, el archivo se llama `maria-dev.md`.

Copia este contenido en tu archivo y completa los datos:

```markdown
# Nombre y apellido

- Usuario de GitHub: @tu-usuario
- Rol en la primera ronda: Piloto / Navegante / Revisor
- C# (1 a 3):
- Git (1 a 3):
- IA para programar (1 a 3):
- Qué espero del curso:
```

Escala: 1 = poco o nada, 2 = lo uso a veces, 3 = lo uso con frecuencia.
